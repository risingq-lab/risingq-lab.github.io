접근하는 데이터와 목적

이 로컬 서버는 Google Tasks 권한을 사용하여 사용자가 요청한 할 일 목록과 할 일을 조회, 생성, 수정, 이동, 완료 처리 또는 삭제합니다. Google Tasks 데이터는 요청을 처리하기 위해 Google Tasks API와 연결된 MCP 클라이언트 사이에서 전달됩니다.

보관과 공유

Google OAuth 액세스 토큰과 갱신 토큰은 이 컴퓨터의 로컬 데이터베이스에 암호화하여 저장합니다. OAuth 클라이언트 설정 파일도 이 컴퓨터에 저장합니다. 할 일 내용은 이 서버가 별도로 장기 보관하지 않습니다. 서버 작동 기록은 이 컴퓨터에 남을 수 있습니다.

사용자가 MCP 클라이언트에서 할 일 작업을 요청하면 해당 요청과 응답의 내용이 클라이언트에 전달됩니다. 연결된 AI 서비스의 데이터 처리에는 그 서비스의 정책이 적용됩니다. 이 로컬 서버는 광고나 분석용으로 Google Tasks 데이터를 판매하거나 제공하지 않습니다.

보관 기간과 삭제

토큰은 고정된 30일 만료 없이 로컬 데이터베이스에 보관하며, 사용자가 삭제하거나 Google 계정에서 앱 권한을 철회할 때까지 남을 수 있습니다. Google 계정의 연결된 앱 설정에서 권한을 철회할 수 있습니다. 로컬 토큰은 서버의 데이터베이스를 삭제해 제거할 수 있습니다.

보안

서버는 로컬 루프백 주소에서 실행되며, 저장된 Google 토큰은 AES-256-GCM으로 암호화합니다. Google API 통신에는 HTTPS를 사용합니다.

변경

처리 방식이 바뀌면 이 페이지의 내용과 수정일을 갱신합니다.
